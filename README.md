# Kunci Wajah — prototipe HP

Aplikasi web kamera untuk deteksi wajah, mata, dan kedipan. Diproses di perangkat.

## Buka di HP

1. Aktifkan GitHub Pages pada repo ini: Settings → Pages → Branch `main` → folder `/` → Save.
2. Tunggu 1–2 menit, lalu buka:
   `https://purwanc405-pixel.github.io/kunci-wajah-hp/`
3. Di iPhone: buka **Safari** (bukan in-app browser) → Izinkan Kamera.
4. Share → **Add to Home Screen**.

## Cara uji

1. Mulai kamera.
2. Mode demo: hadapkan wajah ke oval, kedipkan mata sekali → layar "Pintu terbuka".
3. Daftar wajah (10 cuplikan) lalu ubah Pengaturan ke **Mode ketat**.
4. PIN cadangan: setel di Pengaturan, buka dengan mengetuk logo 5 kali.

## Batasan

Ini prototipe browser, bukan Face ID. Polar landmark + kedipan. Jangan dipakai sebagai satu-satunya kunci aset bernilai tinggi.
